# NUTROK

Дизайн шаблона не меняется. На страницах другие слова и официальные ссылки.

Площадки: бот магазина, канал магазина, каталог, отзывы, общение, навигация.

Документы открываются по своим адресам. Новых цен, отзывов и гарантий на сайте нет.

Как открыть локально:

```text
py -3.12 -m http.server 5500 --bind 127.0.0.1
```

Адрес: http://127.0.0.1:5500/
